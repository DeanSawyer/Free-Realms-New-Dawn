# Free Realms: New Dawn

**An independent, open-source Free Realms preservation and emulator development project.**

*Preserving the past. Rebuilding the experience. Creating a new dawn.*

## Overview

**Free Realms: New Dawn** is an independent community development initiative focused on preserving, restoring, and extending the experience of *Free Realms*, originally developed by Sony Online Entertainment.

New Dawn builds upon the [Sanctuary server emulator developed by Open Source Free Realms (OSFR)](https://github.com/Open-Source-Free-Realms/Sanctuary). This is a separately maintained fork, not an official OSFR release.

## Goals

- **Preservation:** Research and restore original gameplay behavior and world interactions.
- **Emulator development:** Improve stability, networking, persistence, and maintainability.
- **Gameplay restoration:** Investigate character progression, inventory, quests, activities, pets, and mounts.
- **Development tooling:** Build utilities for diagnostics, NPC management, testing, and world development.
- **Extensibility:** Keep changes documented and sustainable for long-term development.

These are development goals, not statements that all listed systems are complete.

## Project status

**Work in progress — independent development.**

Features may be incomplete or experimental. This repository contains server-emulator code and is not a production-ready replacement for the original Free Realms service. Playing may require a separately obtained compatible game client.

## Development

New Dawn uses the C#/.NET Sanctuary codebase as a foundation. Refer to the solution and project files for current build requirements. We may selectively integrate compatible upstream changes.
